# MVweb Search Dictionaries

Готовые словари синонимов для плагина **MVweb Smart Search**. Плагин подтягивает их по кнопке в админке (вкладка «Синонимы» → «Готовые словари»).

Это staging-версия. Содержимое переносится в отдельный публичный репозиторий (напр. `ViMV9/mvweb-search-dictionaries`), откуда плагин читает `index.json` и файлы `packs/*.json` через raw-ссылки.

## Структура

- `index.json` — манифест: список паков, их версии и относительные пути к JSON.
- `packs/*.json` — сами словари.

## Формат пака

```json
{
  "slug": "electronics-parts",
  "name": "Запчасти для электроники",
  "lang": "ru",
  "version": "2026.07.04",
  "groups": [
    ["акб", "аккумулятор", "батарея", "аккумуляторная батарея"],
    ["дисплей", "экран", "матрица", "тачскрин"]
  ]
}
```

Каждая группа — список взаимозаменяемых терминов. Плагин прогоняет их через тот же токенизатор/стеммер, что и индекс: работают одиночные слова, фразы, латиница, транслит, акронимы и частые опечатки. Регистр и `ё/е` нормализуются автоматически — дублировать варианты не нужно.

## Версионирование

`version` — дата в формате `ГГГГ.ММ.ДД`. При правке пака поднять дату и в `packs/<slug>.json`, и в соответствующей записи `index.json`. Плагин сравнивает версии и показывает бейдж «доступно обновление».

## Правила наполнения

- Термины — в нижнем регистре, без `ё` (пиши `е`).
- Не добавлять стоп-слова и общие слова («для», «купить», «цена»).
- Группа осмысленна от 2 элементов; одиночные записи игнорируются движком.
- Не смешивать разные сущности в одну группу (бренд и деталь — раздельно).
